# AG canary 的宿主与后端分时证据

AG 的独立通道和 canary 比较对应两种不同的资源来源。现有 ResourceGate 使用后端 OS 计数，并保留95%暂停、低于90%连续60秒恢复、30秒陈旧和磁盘储备保护。它不能证明 GitHub Runner 在增加会话后的 CPU、可用内存表现。

新增观察器在采集子进程每10秒读取宿主计数。Linux 使用 `/proc/stat` 和 `MemAvailable`，避免把缓存当成不能使用的内存。只输出有界360个分钟数值摘要，不输出bootId、原始计数或机器名称，不新增源请求、RPC或写入许可，也不追加启动健康等待。关闭RPC时停止本机采样计时器。

新的并发比较必须同时覆盖相同十分钟里的后端和每个会话宿主。缺样、95%超限、重复分钟、重启/计数回退、缺会话、错run/commit或缺宿主证据均拒绝。后端磁盘证据与宿主CPU/内存分开；不把宿主未采磁盘写成一个伪造的安全值。旧累计峰值和缺失宿主证据不能据此授予新扩并发许可。
