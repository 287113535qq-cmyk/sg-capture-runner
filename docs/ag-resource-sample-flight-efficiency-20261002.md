# AG 并行保护检查：合并同一在途只读采样

参考 AG 独立工作通道与共享任务状态的处理方式，Runner 同一进程的多个写入保护同时调用 sample 时，复用正在进行的 OS 只读请求。原实现直到响应返回才记录 lastSample；并发调用可重复发出 resources 请求，并把相同时间的样本再次送入 gate，引发不前进样本保护。此路径是否解释真实资源停顿尚未证明。

现在每次只有一个在途采样，所有调用者等待后分别检查原 gate。原10秒采样频率、30秒失效、CPU/内存95%暂停、低于90%健康60秒及独立空间/数据库hold不变。采样失败只 observe(null) 一次，但全部调用者失败；清除在途引用，后续可以重新读取。没有跨进程缓存，没有缓存池、额度或允许写入标记，不修改已运行版本。

21项受影响本机测试通过，包含80同时检查只发1次只读请求、8个真实形状样本后恢复、超载再次暂停、健康60秒恢复、空间hold不解除、失败传播和后续重读。Linux36933838341已成功（受检5889b15，完整日志SHA 329ea76f826557e698bbc71571e3e977ac63f722727e895b9f5d2c8d0b1cc05b）；这是请求合并正确性验证，未测实采收益。
