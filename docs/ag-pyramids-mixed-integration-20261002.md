# Pyramids 混合功能进入实际解析链

按 AG 的故障分类和独立修复通道，把已审查的 Free→Hold→Free 差异接进 Python、Runner、collector 和新会话 captureBatch。复用固定官方客户端及原8帧证据，不重复旧VM、不恢复作废会话、不增加源额度。

新增独立 `pyramids-free-hold-v1` / bonus4 映射。Hold 内层计数允许已审核的+2/+4，期间外层免费计数冻结；内层明确出口核累计奖励，再恢复外层至完整出口。拒绝其他混合、奖池符号、强制结束、未知字段、缺帧、会话及金额差异。XML重复和嵌套字段由三方分别拒绝。

本机14项Python、13项Node及collector类型检查通过；实际私有8帧在三方正式入口仍为未完成，3条合成终局及31负例一致，原作废样本hash不变。新captureBatch测试逐次核持久化意图和响应，最终只产生一次完整checkpoint。旧普通、独立Hold、免费和major分支回归保持。

真实混合终局尚未观察；接线和合成测试不代表重新准入、源许可或整款玩法覆盖。累计完成仍16/178。Linux结果另记录，未通过前不部署该变化。效率总验收仍需下一独立运行采用增量CAS、采样合并和双Python终审，以及实际自动接力。
