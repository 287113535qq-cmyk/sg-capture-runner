# AG 按游戏加载校验模块

参考AG每个独立worker选择当前game handler的方式，SG会话只加载本款所需collector。原入口每次提前加载NextGen及所有Pearl/Rhino校验器，现在固定白名单延迟加载，首次实际规范化仍运行原完整校验函数，Node模块缓存仅进程内使用。未知模块名拒绝；TypeScript完整检查仍在Linux，不恢复每会话重复构建类型图。XML parser只在当前NextGen请求使用时加载，配置保持原样。

真实独立子进程测试证明Rhino首次规范化输出一致，未加载sg.ingest/sg.pearl/sg.pyramids；原Rhino、Pearl和NextGen实际入口17项检查通过。没有改变请求顺序、会话身份、持久化、金额或终局判定。

本机7对交错顺序冷进程实测：加载模块及首条完整普通局验证中位276.75→130.13ms，减少52.98%；模块55→36，RSS中位115052544→97751040字节。每种方式得到相同字段hash；源请求0、数据库写入0。这个改善只覆盖本机模块加载，约147ms，不能宣称消除了真实91–254秒启动等待或把总采集速度提高52.98%。健康handoff已有独立原始计数重放及鲜读保护，不在此重复修改。

新代码不改变固定34a10ba的健康长时采集；统一Linux和后续运行效果须另验。全部效率优化、实际全游戏终审及自动下一款准入仍未完成。
