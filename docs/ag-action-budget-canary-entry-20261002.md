# 动作资源窗口的有界采集入口

Pyramids 的新资源预算许可绑定已经结清的 49593 完整局及剩余 250257 局，复用不可变全文审查凭证，并重新核对全部 660 个已关闭批次的元数据。历史全文不重复传输；这不表示本次重新鲜读了历史原文。

新入口按 AG 的不可变任务领取方式，在源许可前保存并读回唯一运行领取凭证，每个 worker 另领唯一会话凭证。最多 20 个 worker，每个一批、最多 100 次新 BET，窗口五分钟，禁用自动接力；不会重用旧中断会话或重置已用额度。完成采集后继续只读资源采样，缺失窗口明确未完成。

本机整套验证通过：1456 Runner 测试、425 Python 测试；821 个许可源码文件校验一致，178 张规则卡生成和检查通过。独立 Python 计划、实际 worker 入口、工作流选择、持久领取及资源观察均纳入验证。

当前仅完成本机验证及尚未应用的独立许可。Linux、无源激活、真实资源窗口、吞吐对比及连续接力仍待验收，不能据此宣称全部优化完成或线上提速。
