## 持续处理的边界

- 未适配自然玩法保存原现场并暂挂该游戏，继续其他已支持的 ready 游戏。暂挂游戏与其余待适配游戏仍须完成，不能排除出第一轮。
- 按实际已验证完整局计数，每款累计 300000 后全文终审、归档，再进入下一款。每款规则和分析按 [游戏档案规则](game-rule-archive.md) 保存。
- 终审、矩阵换款和 GitHub 调度可能有正常间隔；持续处理不表示每一秒都有源端请求。
- 真实源端/存储异常、未知结果和空间不足仍保留保护。CPU 或内存任一达到 95% 暂停写入，两个指标低于 90% 连续 60 秒后小批恢复；这不解除其他暂停原因。其余边界见 [规则](rules.md)。
- 正常推进和已知状态不变时不重复提醒；新异常、需用户处理、空间停采或全部完成时报告。
- 全部 178 款第一轮终审及归档完成后关闭采集、两个仓库的采集定时和巡检，不自动开始第二轮。
