# 有界预检通道比较

按AG固定任务清单、独立工作通道、deadline和持久结果的模式，将原串行预检分成三个无依赖组：Python及离线分析检查、collector及协议检查、Runner及20会话持久化检查。全部原检查保留，新增调度器错误收集和超时检查。

每组命令固定，不接受外部任意命令。最多3个组，组内依赖仍串行，全部任务join后才判成功；一组失败不隐藏另一组结果，超时杀掉本组进程树。检查只有离线测试，没有SG、数据库连接或源许可逻辑。

默认仍为1组，未证明效果不启用并行。独立canary用同一Linux机器、同一代码和相同检查清单，顺序1→2→2→1，减小先后次序与冷缓存造成的偏差。输出各组、各命令和整轮耗时及退出码，任一轮失败不算验收通过。不用不同GitHub机器的单次耗时猜测加速。
